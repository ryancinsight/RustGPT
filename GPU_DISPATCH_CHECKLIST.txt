================================================================================
TROUBLESHOOTING CHECKLIST
================================================================================

If GPU utilization is LOW or ZERO:

1. Verify GPU present:
   - Windows: Device Manager -> Display adapters
   - Linux: lspci | grep VGA or nvidia-smi
   - macOS: System Report -> Graphics/Metal

2. Verify GPU features compiled in:
   - Build with: cargo build --release --features gpu-wgpu
   - Check: cargo build --lib --features gpu-wgpu

3. Increase batch size:
   - Too small batches don't saturate GPU
   - Try: --pretrain-batch-size 32 or higher

4. Check GPU memory:
   - Windows: Task Manager -> GPU Memory
   - Linux: nvidia-smi | grep MiB
   - If full: increase swap or reduce batch size

5. Verify logs for GPU init:
   - Should see: "GPU initialization for training complete"
   - If missing: GPU features not enabled or GPU not detected

6. Check GPU dispatch code paths:
   - RichardsGlu.forward_gpu() being called?
   - PolyAttention.forward_gpu() being called?
   - Use debug logging or profiler to verify

TRAINING SPEED:
- Small batches (4): CPU-bound, limited GPU speedup
- Medium batches (32): GPU-bound, 4-6x speedup (RECOMMENDED)
- Large batches (64+): GPU-bound, 5-8x speedup

GPU UTILIZATION:
- 0%: GPU features not enabled or GPU not detected
- 1-30%: Batch size too small or GPU initialization failed
- 30-50%: Suboptimal - increase batch size
- 50-90%: OPTIMAL - GPU is utilized
- 90-100%: Excellent - GPU is fully saturated
