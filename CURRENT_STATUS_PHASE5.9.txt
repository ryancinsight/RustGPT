ARCHITECTURE HIGHLIGHTS
═══════════════════════════════════════════════════════════════════════════════

Unified Shared Component Backend Pattern
──────────────────────────────────────────

  SharedComponentBackend
    ├─ Gpu(Arc<UnifiedGpuBackend>)      [CUDA > Metal > Vulkan]
    └─ Cpu                                [Fallback testing only]

  Key Methods:
    ├─ auto_gpu()                        [Strict auto-detection, no fallback]
    ├─ cpu_only()                        [CPU-only path]
    ├─ require_gpu_operation()           [Panic if CPU selected]
    ├─ require_cpu_operation()           [Panic if GPU selected]
    ├─ forward_attention_gpu()
    ├─ forward_feedforward_gpu()
    └─ forward_temporal_gpu()

GPU Detection Decision Flow
──────────────────────────

  1. Detect Runtime GPU
     CUDA available? → Yes
     Metal available? → Yes (macOS)
     Vulkan available? → Yes
     Result: [CUDA, Metal, Vulkan] detected at runtime

  2. Filter by Compiled Features
     GPU features enabled? → [Depends on build flags]
     Result: [Compiled GPU backends]

  3. Strict Resolution
     GPU detected & compiled? → Use GPU (no fallback)
     GPU detected but not compiled? → ERROR (no silent fallback)
     GPU not detected? → ERROR (strict mode only)

Enforced No-Fallback Semantics
──────────────────────────────

  When SharedComponentBackend::auto_gpu() called:
    ├─ GPU available & compiled → ✅ Success
    ├─ GPU detected but not compiled → ❌ Error (guidance provided)
    └─ No GPU detected → ❌ Error (no CPU fallback)

  When require_gpu_operation(op) called with Cpu backend:
    └─ ❌ Panics immediately (prevents silent CPU execution)

  When require_cpu_operation(op) called with Gpu backend:
    └─ ❌ Panics immediately (prevents GPU-only surprises)
